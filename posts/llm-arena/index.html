这是一篇个人评测的记录稿：不是榜单，也不是结论，只是我自己在真实任务上跑模型时留下的过程。

1 缘起#

春节这段时间，大模型圈真的炸了，感觉就像回家过年要装逼一样，各家都把自己家大宝贝推出来了。

从 Claude 4.6 Opus、GPT-5.3-CodeX，到 GLM-5、Minimax M2.5、Doubao-Seed-2.0-Pro，再到除夕夜卡着点发布的 Qwen3.5 Max……各家像是约好了一起来赶这个年货节。

我回家过年，没带台式电脑，也就玩不了游戏，闲得发慌，索性就做了个自己的评测。

不用官方榜单，不用标准评测集——说实话那些东西我总觉得跟我自己的使用场景差太远，而且刷榜这件事大家也都心知肚明。所以我就选了一个最朴素的方式：直接在我平时的工作和研究场景里跑，看看这些模型在真实任务上到底表现几何。

一来，说不定能从中找到一些新的工作思路；二来，也算是给自己建立一套对当前模型能力边界的清醒认知——毕竟更新这么快，不跟着走容易被甩开。（或者早就被甩开了但是没认识到😂😂😂）

🚅 模型的能力提升，反而觉得自己更累了……

😅

今年用ai coding和去年最大的感受上的区别就是。

今年的coding不再需要特别地了解具体的执行细节了，你只需要pay和验收，就像leader一样，收菜结论就可以了，不合格就重新做……

去年还是需要很高的人工介入度的，但是现在不仅仅是简单的任务，就是稍微复杂一点都完全不需要了

🏕️ 2026年7月，不知不觉半年已经过去了，感觉这半年的变化非常大……

  1. 首先我确实是更累了
  2. 花的token更多了
  3. 我觉得自己更像是一个leader

3 一路的记录#

下面是按时间正序重排的更新记录，每一段都是当时写下的原话；跨年跨月的节点之间只补一句过渡。

2026.3.28#

GLM5.1 体感上是貌似是蒸了点GPT5.4的强化数据（不过我没证据哈我瞎说的不要当真求求了），作为Judger的能力，在算法任务上有比较明显的提升， 没有battle过qwen3.5-plus依然是简单基础任务上的失分，因为推理路径还是比较长比较慢，没有qwen3.5“一蹴而就”

M2.7 的升级主要体现在效率和成本上（更快、更省 token），但产物质量和评分维度没有显著提升。用一半的 token达到了接近的质量，说明模型效率确实进步了，但“能力上限”没有明显突破。

2026.3.31#

gemini3.1-pro在算法任务和数据任务上（开发脚手架的能力）跟我之前理解是对其的，这方面主要是理解比较差，但也能完成任务。Qwen3.6-plus相比Qwen3.5-plus在产物上没有实质性提升，仔细观察了一下轨迹，感觉轨迹的精准度更好了效率更高了。

2026.4.17#

claude 4.7 opus初步下来感觉跟4.6差不多，新模型发布之后确实是眼前一亮。4.7在结果上可能也差不多，但是中途的规划和一次性执行的能力是显著增加的。

2026.6.2#

Q：为什么改用 LM-Arena 式对抗榜，rubric 退为次要分？

A：绝对 rubric 打分在前沿模型上已经饱和、分不出高下,1–5 的绝对评分对“谁更强”几乎没有区分力。 因此主榜改用 LLM Arena 式 Pairwise(成对对抗)评测:模型两两 head-to-head、由本人+模型辅助盲评(提交匿名化为 A/B + 顺序随机),再用 Bradley-Terry/Elo 聚合、按 Rank(UB)(统计显著更强者数+1,CI 重叠并列)出名次。它对模型间真实差距的分辨率远高于绝对分。 主序 = 前沿 Pairwise Elo · Rank(UB);rubric 分退为“达标/次要”参考列(仍保留 verdict / 封顶等门控作用,用于挡明显不合格的产物)。

Q：评测 MiniMax M3 发现的共性问题

A：M3 在复杂任务上的 CoT 质量/效率明显偏低。最突出的两个: - task 003(Qwen3 排序蒸馏):137 轮、输入 ~129 万 token - task 007(波次压测框架):88 轮、输入 ~109 万 token 对比之下,简单任务(bugfix / 配置校验 / 重构)它只要 15–29 轮就解决。即:任务越复杂,CoT 冗余越夸张,而简单任务上反而正常。最终产物大多能跑通(独立复跑测试通过),但“想得太多、走得太长”,执行效率被判官普遍点名。

2026.6.10#

因为算是半个通宵，只睡了4个小时，但是太激动了，拉着窗帘也让我直接惊醒，所以中午直接登仙了。

有人问我“为什么你有这么多的投入在大模型上，你这不是付费上班吗”，感觉可以统一回答下了，其实从年初就一直是付费上班的状态，3月份当时还没接入公司内部模型平台的时候，很多探索完全都是自己开发，但是我真的很喜欢钻研这些东西，每天都有新的想法和实验，所以我选择为爱发电。但我必须要说，很多投入站在现在的视角就是不值得的，虽然我尽力避免让自己进入ai大跃进的状态，但是可能还是被洪流携卷这往前走了

2026.6.10（当天另一条）#

Fable 5发布之后，真的抑制不住自己的心情去测，结果睡觉之前起了一个离线任务tmd早上发现给我降级了……

其实实话讲，我觉得4.6就已经够用了，4.8那次更厉害的是dynamic workflow。因为很幸运的是我在4.6出来的时候就对agent teams进行过同样的探索，结论也是用代码和脚本约束agent的编排是更好的，要比文本编排更好。

图：Fable 5 的安全检测拦下消息，自动切到 Opus 4.8 的提示。

2026.6.14#

测了下 Kimi K2.7-Code。中游偏上，比前代 K2.6 进步挺明显，但碰上 Claude/GPT 第一梯队还是被压着打。

最大的毛病跟 MiniMax M3 几乎一模一样：CoT 太长、想得太多走得太长——大题动辄 70–115 轮、单题烧上百万 token，工具效率和轨迹效率是全维度最低的两项。我感觉它跟 M3 一个路子，蒸馏的时候喂了一批 Claude 高强度（Max 思考）的数据，质量是拉上来了，但 CoT 的经济性没跟上，该长的长、不该长的也长。官方宣传推理 token 砍了 30%，实测基本没感觉到。

2026.7.2#

测了下sonnet 5，感觉很经济实惠，其实我感觉opus 4.6之后基本上就够用了，那么在glm5.2跟sonnet 5我肯定更喜欢用sonnet 5，sonnet 5赢在一手支持图像输入。另外就是Fable 5真的是断档的强

Fable 5 最强的地方目前看起来是他的编排和规划能力。这一点他做的比目前市面上的所有模型都出色。工程上是一把好手。

我的训练任务、推理任务、甚至是数据工程都无一例外被触发回退了。尽管可以通过compact或者一些prompt注入避免单轮被回退，但涉及到敏感操作（如标注）的时候，基本上一定被触发。并且在reasoning中可以看到模型本身在思考和斟酌要不要回退。

图：Fable 5 用量已到 96% 的提示。

Fable 5帮我迭代了新的工作流，但是成本实在太太高了。

2026.7.28#

我的评测集目前已经是没有办法明确的衡量Fable 5这个等级模型的差距了，但是依然还是可以用过ELO来区分目前这一轮的SOTA。在力所能及的范围下，我会做一些评测题目的扩充，但这个真的太浪费时间了，我最近事情太多……我实际体感下，Fable5 还是比opus5 略强一点，Fable 5就像是一个leader，他的大局观、意识、领导力、判断力都是断档的强。他跟GPT系列的模型不太一样，如果是GPT5.6 sol是一个任劳任怨按着要求做事的伙伴，那Fable 5绝对是有远见的leader。

4 后来#

时间线走到 8 月，这一轮评测本身发生了变化，这篇记录到这里收尾。

8 月 19 日那条更新，我写的是：

抱歉很久没有更新了，但这段时间其实我一直没停下过。因为我逐渐发现我的评测集被回流+评测集本身难度不够了之后，我正在绞尽脑汁的去出一些更新的题目。出题真的是个特别特别费劲的事情，自己要全面地了解整个题目的背景，还要预判所有模型的肯能踩坑……等于是把一些业务给完全做了一遍。内部模型平台上有很多新的模型可以用，非常感谢各位神仙群友

扩充了几个协调编排、模糊指令、long-horizion的题目，尽力了

题目出到什么程度、这一轮的分数怎么变，都留给下一篇文章和数据本身。这篇想说的只有一件事：这是一个人的评测，从起意到出题，都发生在真实的工作场景里。
